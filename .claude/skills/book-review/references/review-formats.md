# Форматы рецензий

## 1. Внутренняя издательская рецензия (reader's report)

Объём: 1–3 страницы (3 000–9 000 знаков). Адресат: редактор, издатель, литагент, автор.

```markdown
# Рецензия: <название>, <автор>
Жанр / объём / аудитория: <…>
Рецензент: <агентство>; дата: <…>

## Вердикт
<одна фраза: брать / брать после доработки / отказать — и главная причина>

## О чём книга
<логлайн и краткое изложение, включая финал (до 1 500 знаков)>

## Сильные стороны
<3–5 пунктов, каждый с цитатой или эпизодом>

## Слабые стороны
<3–5 пунктов по убыванию важности, каждый с местом в тексте и последствием для читателя>

## Оценка по рубрике
<таблица из notes/audit-review.md, итог и порог>

## Рынок
- Аудитория: <кто купит, где узнает>
- Сравнимые книги: <2–4 проверенных: автор, название, год — чем похожа, чем отличается>
- Позиционирование: <полка, сильный крючок для аннотации>

## План доработки
<3–7 правок по приоритету: что, где, кто из агентства выполнит>
```

## 2. Публичная критическая рецензия

Объём: 4 000–12 000 знаков (журнал, медиа), 2 000–5 000 (блог). Адресат: читатель, который решает, читать ли.

Структура:
1. **Вход** — сцена, цитата, парадокс или контекст, а не «Перед нами новый роман…».
2. **О чём** — завязка без спойлеров, 2–4 предложения.
3. **Тезис рецензента** — что эта книга делает и насколько удачно, одним-двумя предложениями.
4. **Аргументы** — 2–4 блока: язык, герои, конструкция, тема, место в традиции; каждый с цитатой.
5. **Что не получилось** — честно и конкретно.
6. **Для кого** — кому понравится, кому нет.
7. **Финал** — мысль, а не «рекомендую к прочтению».

## 3. Короткий отзыв (маркетплейс, соцсети, LiveLib/Goodreads)

Объём: 500–1 500 знаков. Личное впечатление + одна конкретная деталь + кому подойдёт + оценка (если площадка требует). Без спойлеров. Без пересказа аннотации.

## 4. Блёрб (рекомендательная фраза)

1–3 предложения для обложки или подборки. Конкретный образ или сравнение, а не набор эпитетов. Не выдавать за слова реального человека или издания.

## Штампы рецензий — не использовать

«читается на одном дыхании», «не оставит равнодушным», «пронзительная история», «глубокие характеры», «неожиданный финал» (без конкретики), «must read», «перед нами», «автор поднимает важные темы», «книга заставляет задуматься», «рекомендую всем».

## Критерии хорошей рецензии

- Читатель понимает, о чём книга и для кого она.
- Каждое суждение подкреплено текстом.
- Есть позиция, с которой можно спорить.
- Рецензию интересно читать, даже не собираясь читать книгу.
