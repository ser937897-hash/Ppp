# Структуры и жанровые каноны

## Нон-фикшн

- **Перевёрнутая пирамида** (новости): главное → подробности → контекст. Лид отвечает на «кто, что, где, когда, почему».
- **Лонгрид / фичер**: зацепка-сцена → «нат-граф» (почему это важно сейчас) → развитие через героев и факты → поворот/сложность → вывод, возвращающий к начальной сцене.
- **Эссе / колонка**: тезис → доводы с примерами → сильнейшее возражение и ответ на него → вывод, который продвигает мысль, а не повторяет её.
- **Гайд / how-to**: результат, который получит читатель → что понадобится → шаги (один шаг — одно действие) → частые ошибки → что дальше.
- **Пирамида Минто** (деловые тексты, отчёты): вывод сверху, ниже — группы доводов (MECE), ещё ниже — данные.
- **SCQA**: ситуация → осложнение → вопрос → ответ (вступления, презентации, питчи).
- **Речь**: обещание → три опоры → история → призыв; фразы короче, повторы ключевой мысли допустимы.

## Коммерческие тексты

- **AIDA**: внимание → интерес → желание → действие.
- **PAS**: проблема → обострение → решение.
- **4U** для заголовков: полезность, уникальность, срочность, конкретика.
- **JTBD**: пиши от задачи клиента, а не от характеристик продукта.

## Художественная проза

- **Трёхактная структура**: завязка (до ~25%: мир, герой, побуждающее событие, первый поворот) → конфронтация (~50%: нарастание, мидпойнт, кризис) → развязка (~25%: кульминация, новая норма).
- **Путь героя** (Кэмпбелл / Воглер, 12 шагов) — для приключенческих и мифологичных сюжетов.
- **Save the Cat** (Блейк Снайдер, 15 битов) — для жанровой прозы и сценариев.
- **Кисётэнкэцу** (вступление, развитие, поворот, сведение) — без центрального конфликта, для камерной прозы.
- **Снежинка** (Рэнди Ингермансон) — метод планирования: от одной фразы к синопсису и поэпизоднику.
- **Сцена и последствие** (Дуайт Суэйн): сцена = цель → конфликт → неудача/поворот; последствие = реакция → дилемма → решение.
- **Арка персонажа**: ложное убеждение (Ложь) → желание vs. потребность → испытания → правда / трагический отказ.
- Рассказ: одно главное событие, минимум персонажей, начало максимально близко к кульминации, финал меняет понимание.
- Чехов: ружьё стреляет; ничего лишнего. Хемингуэй: принцип айсберга — подтекст сильнее сказанного.

## Сценарий

- Формат: заголовок сцены (ИНТ./НАТ. МЕСТО — ВРЕМЯ), описание действия в настоящем времени, реплики. 1 страница ≈ 1 минута экранного времени.
- Короткое видео (Reels/Shorts): хук в первые 1–3 секунды → ценность → поворот/пэйофф → призыв. Одна мысль на ролик.
- YouTube 8–15 мин: хук и обещание (0:00–0:30) → контекст → блоки с «открытыми петлями» → кульминация → призыв.
- Подкаст: холодное открытие → вступление → сегменты → итог. Пиши для уха: короткие фразы, никаких скобок и сносок.
- Сценарий в две колонки (видео / звук) — для рекламы и обучающих роликов.
